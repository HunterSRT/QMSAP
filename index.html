📊 Arithmetic Mean (x̄)

x̄ = (Σ xᵢ) / n
The average of all QC values. Used as the lab mean for performance evaluation.

Standard Deviation (SD)

SD = √[ Σ(xᵢ - x̄)² / (n - 1) ]
Measures the dispersion of values around the mean. Uses sample SD (n-1 denominator).

📈 Coefficient of Variation (CV%)

CV% = (SD / |Mean|) × 100
Expresses imprecision as a percentage. Lower CV = better precision. Compared against permissible CV and factory CV.

️ Bias%

Bias% = | (Lab Mean − Target Mean) / Target Mean | × 100
Measures systematic error (accuracy). Target can be factory mean or peer group mean.

🎯 Sigma Metric (σ)

σ = (TEa − |Bias%|) / CV%
Combines bias and imprecision into a single quality metric.
σ ≥ 6: World Class  |  5–6: Excellent  |  4–5: Good  |  3–4: Marginal  |  < 3: Unacceptable

Quality Goal Index (QGI)

QGI = |Bias%| / (1.65 × CV%)
Diagnoses the type of error when σ < 6:
QGI < 0.8 → Random Error (improve precision)
0.8 ≤ QGI ≤ 1.2 → Combined Error (improve both)
QGI > 1.2 → Systematic Error (improve accuracy)

📋 Westgard Multi-Rules

1-2s (warning) | 1-3s, 2-2s, R-4s, 4-1s, 8-x (reject)
1-3s: One point beyond ±3SD → reject
2-2s: Two consecutive points beyond ±2SD on same side → reject
R-4s: Range between two consecutive points exceeds 4SD → reject
4-1s: Four consecutive points beyond ±1SD on same side → reject
8-x: Eight consecutive points on same side of mean → reject

️ Total Allowable Error (TEa)

TEa = Maximum acceptable error for clinical decision
Set by regulatory bodies (CLIA, Rilibak, RCPA) or derived from Biological Variation data (EFLM). Used in Sigma calculation. Sources:
• CLIA'88 (USA) — Regulatory
• Rilibak (Germany) — Guidelines
• RCPA (Australia) — Recommendations
• EFLM Biological Variation — Scientific model
