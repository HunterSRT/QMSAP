Sigma Performance
🎯 Quality Goal Index (QGI)
σ ≥ 6: World Class
5 ≤ σ < 6: Excellent
4 ≤ σ < 5: Good
3 ≤ σ < 4: Marginal
σ < 3: Unacceptable
QGI = |Bias| / (1.65 × CV)
QGI < 0.8: Random Error
0.8 ≤ QGI ≤ 1.2: Combined
QGI > 1.2: Systematic Error
